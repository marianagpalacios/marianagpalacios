# 🧬 Projetos em destaque

## 🌿 BioTrace

**Plataforma open source para análise reproduzível de sequências biológicas.**

O BioTrace é um projeto pessoal de software científico voltado ao processamento e análise de sequências de DNA a partir de arquivos **FASTA e FASTQ**.

### Principais funcionalidades

- validação de sequências;
- controle de qualidade de reads FASTQ;
- trimming e filtros de comprimento;
- tratamento de orientação forward/reverse complement;
- alinhamento pairwise;
- integração com **BLAST local**;
- cálculo de identidade e cobertura;
- ranking de resultados;
- classificação baseada em banco de referência;
- geração de indicadores;
- relatórios em JSON, CSV e Markdown;
- registro de informações de proveniência;
- cache de análises;
- banco de referência versionado;
- interface com Streamlit;
- testes automatizados;
- integração contínua.

### Tecnologias

`Python` · `Biopython` · `Streamlit` · `BLAST` · `Pytest` · `GitHub Actions`

O projeto prioriza **reprodutibilidade computacional, rastreabilidade das análises e explicitação das limitações científicas dos dados utilizados**.

> A base atualmente distribuída com o projeto é reduzida e destinada a fins educacionais e experimentais. Seus resultados não devem ser utilizados isoladamente para conclusões taxonômicas, ecológicas, clínicas ou ambientais.

🔗 **Repositório:** [github.com/marianagpalacios/BioTrace](https://github.com/marianagpalacios/BioTrace)

## 🗄️ DataLake

### Principais funcionalidades

- ingestão de arquivos CSV;
- preservação da camada de dados brutos;
- identificação de arquivos por SHA-256;
- pipeline ETL;
- validação estrutural e linha a linha;
- separação de registros válidos e rejeitados;
- geração de métricas de qualidade;
- staging em PostgreSQL;
- rastreabilidade das execuções;
- data lineage;
- idempotência;
- reprocessamento controlado;
- API REST;
- paginação e filtros;
- testes automatizados;
- cobertura de testes;
- integração contínua;
- containerização com Docker.

### Tecnologias

`Python` · `PostgreSQL` · `Pandas` · `FastAPI` · `Pydantic` · `SQLAlchemy` · `Alembic` · `Docker` · `Pytest` · `GitHub Actions`

O projeto foi desenvolvido com foco em **qualidade de dados, rastreabilidade, separação de responsabilidades, testabilidade e reprodutibilidade**.
